# 🛒 Dakshini Store Data Analysis

## 📌 Project Overview

An Excel-based data analysis project focused on analyzing store sales performance and extracting actionable business insights.

The project demonstrates how Microsoft Excel can be used to transform raw transactional data into meaningful analysis using data cleaning, formulas, PivotTables, and data visualization.

---

## 🎯 Business Objective

The objective of this project is to analyze store sales data and answer key business questions such as:

* Which products and categories generate the most revenue?
* Which regions perform the best?
* What are the major sales trends?
* Which customer segments contribute the most to sales?
* Where are potential opportunities for improving business performance?

---

## 🗂️ Dataset

The analysis is performed on transactional store data containing information related to sales, products, customers, regions, and other business attributes.

The dataset was cleaned and prepared before performing the analysis.
